- SharedArrayBuffer
    - A raw block of binary memory shared between threads. Zero Copy
- Int32Array(sharedBuffer)
    - A typed view over the shared buffer

    - const sharedBuffer = new SharedArrayBuffer(4);
    - const sharedArray = new Int32Array(sharedBuffer);
    - sharedArray[0] = 0;

- Atomics
    - Atomic.wait(sharedBuffer , 0 , 0) - block this thread until sharedBuffer[0] changes from 0
    - Atomic.notify(sharedBuffer, 1) - awake waiting thread
    - Atomic.add()
